# Voice samples

Paste 3 to 5 real things the writer wrote here. Old LinkedIn posts that felt right are best. Long Slack messages or emails to friends work too.

The skill reads this file before it writes. It copies habits, like how you open and how long your lines run. It never copies whole sentences.

A short note on each one helps, like "this one did well" or "too stiff, don't copy".
